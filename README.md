# web-design-ai-assistant
Ai-ассистент веб-дизайнера на базе OpenCode. Помогает решить проблему "чистого листа", хорошо проводит исследования, находит референсы, предлагает и анализирует варианты, может выступить критиком и оппонентом. Очень быстро делает прототипы для продуктовых команд. Верстает лендинги и веб-страницы.
