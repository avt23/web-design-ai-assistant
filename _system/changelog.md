# Changelog системы

Журнал изменений инфраструктуры агента: skills, субагенты, MCP, промпты, скрипты.
Ведёт **настройщик**. Формат: дата — что изменилось — зачем.

---

## 2026-08-04

### Добавлено
- Создана папка `_system/` для документации инфраструктуры (отдельно от `_tasks/`).
- Создан `_system/inventory.md` — реестр всех инструментов агента (skills, субагенты, MCP, скрипты, промпты, хранилища, env).
- Создан `_system/changelog.md` — этот журнал.
- Создан `_system/todo.md` — список идей и планов по развитию системы.

### Идея
- Разделение ролей: дизайнер (пользователь) и настройщик (администратор). Дизайнер не настраивает систему — это прописывается в промпте.
- Перенос проекта на VPS для круглосуточной работы дизайнера. На VPS настройщик настраивает один раз, дизайнер только пользуется.
